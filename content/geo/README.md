# Геоданные карты истории

- `kz-modern.geojson` — граница Казахстана, Natural Earth 1:50m (public domain).
- `kz-regions.geojson` — области и города республиканского значения, Natural Earth, деление до реформы 2022 года.
- `eras/*.geojson` — контуры эпох из дизайна команды. Исторические территории (Ак Орда, ханство, империя, СССР) взяты из проекта historical-basemaps (GPL-3.0, https://github.com/aourednik/historical-basemaps); контуры с `"approximate": true` (саки, тюркские каганаты) нарисованы вручную как примерные зоны.
